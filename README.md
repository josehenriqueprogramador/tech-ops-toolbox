# Tech Ops Toolbox 🛠️

Uma suite profissional de scripts voltada para **Engenharia de Operações** e **Ciência de Dados**. Este projeto automatiza tarefas críticas de infraestrutura e transforma logs brutos em insights estruturados.

---

## 📂 Estrutura do Projeto

### 📊 Analytics
- **analisador_logs.py**: Processamento estatístico de logs usando Regex.
- Gera relatórios automáticos em formato JSON.

### 🤖 Automation
- **backup_manager.py**: Gestão de backups com data/hora dinâmica.
- Sistema de retenção inteligente (mantém apenas os últimos 5 arquivos).

### 🛰️ Monitoring
- **verificar_servico.sh**: Check rápido de processos em execução (Bash).
- **valida_api.py**: Monitor de status e disponibilidade de endpoints (Python).

---

## 🚀 Guia de Uso

1. **Instalar Dependências**:
   `pip install requests`

2. **Executar Automação**:
   `python automation/backup_manager.py`

3. **Analisar Tráfego**:
   `python analytics/analisador_logs.py`
