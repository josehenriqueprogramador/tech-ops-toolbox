# Tech Ops Toolbox 🛠️

Repositório dedicado a ferramentas de monitoramento e automação para infraestrutura e suporte.

## 📂 Estrutura do Projeto

* **`bash/`**: Contém scripts de automação para servidores e serviços Linux.
    * `verificar_servico.sh`: Monitora se um serviço específico está rodando.
* **`python/`**: Scripts para integração e monitoramento de APIs.
    * `valida_api.py`: Valida o status de endpoints externos.

## 🚀 Como usar
Ideal para ser utilizado em ambientes de servidores via terminal ou integrados a cronjobs.
